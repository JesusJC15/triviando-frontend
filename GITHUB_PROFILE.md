## 🧑‍💻 Featured Projects

### 🔹 TrivIAndo - Real-Time Trivia Platform (Full Stack)
- Designed and developed a **real-time multiplayer trivia game platform** with interactive buzzer mechanics and live chat functionality.
- **Frontend:** React 18, TypeScript, Tailwind CSS, Socket.IO Client, React Router, TanStack Query, Framer Motion.
- **Backend:** Node.js, Socket.IO (WebSocket), REST APIs, JWT Authentication.
- **Key Features:**
  - Real-time multiplayer game rooms with buzzer mechanics
  - Live chat system within game rooms
  - Player authentication and session management
  - Dynamic trivia generation and question display
  - Live leaderboard and ranking system
  - Responsive UI with smooth animations
- **Testing:** Comprehensive test suite with Vitest and Testing Library (20+ test files)
- **CI/CD:** Automated deployment pipeline using GitHub Actions and Azure Web Apps
- Applied best practices including:
  - Clean architecture with layered separation (features, services, API clients)
  - TypeScript for type safety
  - Custom hooks for business logic reusability
  - Centralized API endpoint management
  - WebSocket connection handling with auto-reconnection
  - Test-driven development approach
